### 复用 Prompt

```text

创建一个 Markdown 驱动的个人学习档案网站，部署到 GitHub Pages。

# Vibe
风格：简约黑白灰、轻微磨砂、克制留白、高对比、无渐变、无大卡片阵列。
设计要求：字号、字体、颜色等建立规范，统一样式

# 核心页面
首页：
- 基于学习计划表（网址）显示已完成 Task 数量与进度条。
- 列为：Task、计划、学习记录、难度、任务与阅读笔记。
- 未完成、无记录或未公开笔记使用浅灰色和锁图标，不显示“未解锁”。

文章页：
- 左侧为 Task 0—9 折叠导航。
- 一级是 Task 编号与标题。
- 二级是任务笔记及对应 F / P / D / I 阅读笔记。
- Task 笔记结构：任务说明、Checklist、心得。
- 阅读笔记结构：原阅读文章、Takeaway、学习过程中的随笔。
- 标题和图片适中，正文排版紧凑。

# 规则：
- GitHub Actions 在 push 后构建 dist 并发布 Pages。
- 响应式支持手机，不允许横向滚动。
- 不直接维护生成后的 HTML。
- 完成本地预览后先让我确认，不要 commit。

```

### 10 分钟流程

1. **0—2 分钟：写简报**  
   确定网站名称、首页重点、内容类型、文章结构、视觉风格，以及明确不要出现的设计。
2. **2—4 分钟：复制模板或让AI直接生成**  
   从 GitHub Template 创建仓库，执行 `npm install && npm run dev`。
3. **4—6 分钟：修改配置**  
   填写站点信息、Task 标题、截止时间和阅读文章关系，不直接维护生成后的 HTML。
4. **6—8 分钟：放入真实内容**  
   加入一篇 Task 笔记和一篇阅读笔记，将 `draft` 改为 `false`，确认页面能够生成。
5. **8—9 分钟：调整视觉变量**  
   只调整颜色、页面宽度、标题字号、区块间距和图片宽度。
6. **9—10 分钟：检查并发布**  
   检查首页层级、锁定状态、文章可读性和移动端，再提交并推送。
